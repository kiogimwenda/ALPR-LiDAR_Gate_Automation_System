# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
responsibly by emailing **kiogoraian254@gmail.com** with the subject line
`[SECURITY] ALPR-LiDAR Gate Automation`.

Do **not** open a public GitHub issue for security vulnerabilities.

## Scope

This project controls physical gate hardware. Security issues that could lead
to unauthorized gate opening, denial of service of the access-control system,
or exposure of vehicle plate data are treated as critical.

## Response

We aim to acknowledge reports within 48 hours and provide a fix or mitigation
within 7 days for critical issues.
